# Кольцевая диаграмма — frontend №71 без API

## Что реализовано

- SVG-кольцо с зелёно-серой палитрой актуального макета. Внутренний радиус уменьшен с примерно 64% до 54% внешнего: белый центр меньше, кольцо толще.
- При наведении на сегмент или категорию под кольцом показываются название, сумма в рублях и доля. Активный сегмент выделяется, остальные приглушаются. Блок подсказки находится внутри карточки и доступен указателю, без таймера исчезновения.
- Выбор сегмента или кнопки легенды закрепляет категорию: это также позволяет пользоваться графиком без наведения. Tab переводит фокус по легенде и обновляет подробности, Enter/пробел выбирает категорию, Escape сбрасывает подсказку и выбор.
- У категорий есть текстовые суммы и проценты, доступные без SVG; изменения подсказки сообщаются через status. Легенда использует те же цвета, что и сегменты.
- Пустой или нулевой набор отображает сообщение об отсутствии расходов; не рисуются нулевые сегменты. Одна ненулевая категория корректно занимает всё кольцо. Расчёт долей сохранён, округлённые проценты суммируются до 100%.
- Деньги и категории приходят в компонент через существующую внутреннюю модель CategoryTotal. Геометрия отделена в categoryChartModel.ts, новые библиотеки не добавлены.

## Ограничения

API Dashboard отсутствует по подтверждению команды. В DEV-демосессии используются явно обозначенные синтетические данные; в обычной сессии тестовые категории не подставляются. Запросов к выдуманным эндпоинтам нет. При появлении backend нужно согласовать DTO, подключить адаптер и проверить реальные суммы/валюты/ошибки.

Loading/error/пустой список Dashboard сохраняют прежнюю обработку родительской страницы. Статистику реального backend эта работа не подтверждает. Независимое ревью, CI и закрытие задачи ещё требуются.

## Как проверить

Из frontend: `npm.cmd test`, `npm.cmd run build`. Запуск DEV: `npm.cmd run dev -- --host 127.0.0.1 --port 3001`.

На странице входа выбрать «Открыть демо меню» и Dashboard. Проверить указателем сегменты, затем выбрать категорию в легенде, перейти Tab к следующей, нажать Enter/пробел и Escape. На узком экране выбор категории доступен нажатием. Через «Состояния демонстрации» внизу доступны загрузка, пустой список и ошибка.

Проверка Docker frontend из корня: `docker compose up -d --build frontend`. Полный стек требует локального .env и работающего backend; производственная сборка не содержит демо-входа.

## Выполненная проверка

- 64/64 локальных теста проходят, typecheck и production build успешны. Проверены пропорции/замыкание кольца, одна категория, нулевые значения, неизменность исходных сумм и текстовые доступные альтернативы.
- В браузере проверены выбор сегмента и легенды, смена подробностей через Tab, Enter/пробел, сброс через Escape. Исправлен приоритет клавиатуры над оставшимся на другой категории курсором. Отдельного автоматизированного наведения без клика доступные средства браузера не предоставляют; обработчики pointer-enter добавлены, выбор указателем проверен.
- На ширине 320 и 375 px документ без горизонтального переполнения, кольцо и кнопки помещаются. Это проверка Chromium viewport и клика, не физического телефона или реального touch-события. Viewport восстановлен.
- Docker frontend собран и запущен через compose; backend/БД не пересоздавались. Независимый approve и серверный CI этим не подтверждены. Статус публикации ветки и ревью нужно проверять в репозитории.
