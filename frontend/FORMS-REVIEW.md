# Формы подписок: происхождение и текущий статус

Исходный интерфейс Полины перенесён ранее из коммита `09a0cc9` с сохранением авторства, без посторонних backend-коммитов. Её ветка этой работой не изменялась.

## Ранее исправлено

- Ложный успех пустых обработчиков заменён честным предупреждением о предпросмотре.
- Меню последней строки не обрезается таблицей; доступно с клавиатуры, закрывается по Escape.
- Окно удаления переведено на dialog с управлением фокусом.
- Десятичные суммы проверяются без экспоненциальной/hex-записи и долей минимальной денежной единицы; календарные даты проверяются на существование.

## После подключения API

- Создание/редактирование используют один SubscriptionForm и SubscriptionEditor.
- Предупреждение о несохранении осталось только в DEV-демо. Реальные операции выполняются через POST/PUT/DELETE и подтверждаются успешным ответом backend.
- Категории приходят через GET /api/categories, в запрос передаётся categoryId.
- Сумма формы — полная стоимость выбранного периода. Поддержаны все валюты/периоды Swagger, включая CUSTOM/periodDays; месячный пересчёт не придуман.
- Прямой URL редактирования загружает свою запись через полный GET /api/subscriptions/me, а не полагается на navigation state.
- Loading/error/retry, пустой справочник, отмена запросов, повторные нажатия, истёкшая сессия и неопределённый результат сетевого сбоя обработаны.
- Подтверждение удаления отправляет DELETE; до успешного ответа UI не удаляет строку и не показывает успех.
- Для успешного создания/обновления/удаления добавлены toast; ошибки удаления видны внутри модального dialog. Выполнена дополнительная responsive-проверка и исправлены найденные проблемы; см. MOBILE-CHECK.md.

Проверки: сборка, unit-тесты, реальные запросы на отдельных разрешённых тестовых данных; браузерные сценарии описаны в SUBSCRIPTIONS.md.
Это проверка агентом, а не независимый approve Ивана/команды. Коммит, публикация и слияние для этой интеграции пока не выполнялись.
