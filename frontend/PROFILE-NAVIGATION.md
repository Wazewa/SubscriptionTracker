# Переход в настройки из профиля — задача №129

Иконка аккаунта в общей шапке ведёт на `/settings` со всех закрытых страниц.
Используется ссылка React Router: переход сохраняет сессию и историю браузера.
На странице настроек ссылка отмечается `aria-current="page"`.
У иконки есть доступное название «Аккаунт — настройки», подсказка,
видимый фокус клавиатуры и область нажатия 44×44 px.

## Проверка

1. Запустить приложение и войти. Для проверки без backend в dev-режиме
   можно использовать «Открыть демо меню» на странице входа.
2. На Дашборде нажать иконку аккаунта: адрес `/settings`, заголовок «Настройки».
3. Повторить со страницы подписок, создания и редактирования подписки.
4. Выделить ссылку клавишей Tab и нажать Enter: результат тот же.
5. Проверить Назад/Вперёд, обновление `/settings` и мобильную ширину.
6. После выхода открыть `/settings`: приложение переводит на `/login`.

`npm test` проверяет адрес ссылки на всех закрытых страницах и её активное
состояние. Перед ревью также выполнить `npm run typecheck` и `npm run build`.
Проверка контейнера: `docker compose up -d --build frontend`.

Задача №121 также содержит требование перехода по профилю. Для этой части
используется та же общая ссылка; отдельный обработчик не нужен.
